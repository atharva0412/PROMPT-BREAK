# PROMPT//BREAK

**PROMPT//BREAK** is a browser-based puzzle-action game where players don't just control the character — they can also change the game world using simple commands.

The player is trapped inside an unstable AI-generated world and must reach the exit while dealing with gaps, enemies, and changing environments.

### 🎯 How to Play

Players can use commands such as:

* **CREATE PLATFORM** — creates a platform to cross gaps
* **DELETE ENEMY** — removes an enemy blocking the path
* **FREEZE ENEMIES** — temporarily stops enemies
* **REVERSE GRAVITY** — changes the direction of gravity

Every command uses energy, so players need to think carefully about when to use each command.

### ✨ What Makes It Different?

The main idea is that **prompting is part of the gameplay**. Instead of only controlling a character, players can modify the environment through commands and find different ways to solve a level.

### 🛠️ Built With

* HTML
* CSS
* JavaScript

### 🎮 Game Objective

Solve the levels, manage your limited energy, avoid or control enemies, and reach the exit.
